# Security boundaries

- Renderer: `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`; fixed preload API; privileged handlers validate Zod input and require the app's main frame. Navigation and new windows are blocked. CSP restricts scripts to local assets.
- Stream lifecycle: native confirmation yields a single-use operation-specific token, expiring in 30 seconds. Plan creation/editing invalidates tokens. No director action can start or stop streaming. Failed or unconfirmed transitions leave a recoverable, paused session.
- Director: untrusted chat is topic data. It can select only known contextual copy, never tools, raw HTML, addresses or commands. Action schemas and policy enforce safe registered operations, overlay permission, privacy checks, cooldowns, connected OBS and a staged overlay. Scene automation is not enabled in this release.
- Twitch: public-client device authorization needs no bundled secret; trusted official HTTPS authorization and WSS reconnect hosts, generation-based cancellation, refresh, hourly token validation and serialized credential deletion. Tokens stay in memory by default. Explicitly remembering connections enables OS-backed encryption; saved OBS credentials use the same opt-in. Startup does not access Keychain in the default session-only mode. Transient HTTP requests time out.
- Overlay: binds only to IPv4 loopback. A random URL token authenticates reads; Host/Origin validation reduces cross-origin access. No HTTP control endpoint exists. Text uses `textContent`. Verification distinguishes local state publication from browser acknowledgement; neither implies the public Twitch audience saw it.
- Storage: sessions and audit records use SQLite transactions and parameterized writes. The database contains chat and creative briefs and is not encrypted. Use Delete local history to clear it; it is not a forensic disk erase.
- Provider: model requests are optional, main-process only, structured and locally validated. Secrets and raw provider output are not sent to the renderer. Setting a model key enables sending your brief in real mode. `store:false` is requested; review your provider account's retention controls separately.
- Scope: local OBS only. Remote browser sources, public posting, vision capture, audio capture and autonomous polls are not implemented.

Installed runtime configuration is stored outside the application bundle in an owner-readable `config.env` (mode 0600). Only CUE runtime keys are imported from the development `.env`; unrelated secrets and renderer navigation settings are excluded.
