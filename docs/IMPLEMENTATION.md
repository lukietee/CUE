Recap improvement suggestions are template recommendations; engagement lift and causal outcomes are not calculated.

Validation now includes unit/integration tests, packaged Electron demo rehearsals, production password retry, session-only restart, optional encrypted reconnection, and Finder-style configuration/single-instance checks. Real Twitch application registration and OpenAI planning have been checked using local configuration.
