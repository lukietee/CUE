# Project workflow

- Commit regularly at meaningful, reviewable milestones.
- Create pull requests for project changes when a Git remote is available.
- Review and approve pull requests when warranted by the changes and validation, and when the authenticated account is permitted to approve. Do not bypass platform restrictions on approving your own pull requests.
